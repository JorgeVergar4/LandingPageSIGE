# SIGE

Sistema Integral de Gestion de Escuderias.

Landing multi-pagina con enfoque premium inspirada en marcas de alto rendimiento.

## Estructura

- index.html: portada y propuesta de valor.
- servicios.html: servicios y planes de precios.
- nosotros.html: equipo y perfil del desarrollador.
- blog.html: publicaciones tecnicas.
- contacto.html: formulario y canales de contacto.
- css/styles.css: sistema visual global y componentes.
- js/index.js: navbar responsive, estado de header y animaciones de entrada.

## Tecnologias

- HTML5 semantico
- CSS3 (variables, grid, flex, responsive)
- JavaScript vanilla

## Notas de mantenimiento

- Navbar y footer estan unificados en todas las paginas.
- La clase active del menu se calcula automaticamente via JavaScript.
- Los fondos hero se controlan por clase de pagina en CSS para evitar estilos inline.
